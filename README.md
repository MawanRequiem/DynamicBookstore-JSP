# 📚 Dynamic Bookstore (JSP Edition)

A dynamic, full-stack Java web application built with Java Server Pages (JSP), Servlets, and MySQL. This bookstore system allows users to browse and purchase books, while administrators manage book listings and oversee transactions.

![Built with JSP](https://img.shields.io/badge/Built%20With-JSP-blue)
![Database](https://img.shields.io/badge/Database-MySQL-orange)

---

## 📌 Features

### 👤 User

* Register and log in
* Browse book catalog
* Add books to cart
* Checkout and create transactions
* View order history

### 🔐 Admin

* Secure admin login
* Add, update, or delete book listings
* View all customer transactions
* Change transaction statuses

---

## 🛠 Tech Stack

| Layer    | Technology          |
| -------- | ------------------- |
| Frontend | HTML, JSP, CSS      |
| Backend  | Java Servlets, JSP  |
| Database | MySQL + JDBC        |
| Server   | Apache Tomcat (8/9) |
